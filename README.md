# Трекер обращений и отвлечений

Личная PWA для телефона и компьютера. Нажмите «Отвлекли», чтобы запустить таймер, и «Завершить», чтобы сохранить обращение. В журнале можно добавить прошедшее обращение, уточнить детали, посмотреть сводку за день или неделю и выгрузить данные в JSON/CSV.

Оба устройства работают с одной Cloudflare D1. Один Worker обслуживает интерфейс и API по HTTPS, Cloudflare Access открывает их владельцу по email. После первого запуска в браузере приложение можно установить через его меню или добавить на экран «Домой» в Safari. После начальной синхронизации журнал доступен без сети. Изменения записываются на устройство и отправляются в D1 после восстановления связи. Разбор через модель и выгрузка из облака доступны онлайн.

## Разбор через модель

В настройках выберите OpenRouter, CheapAI или свой OpenAI-совместимый Chat Completions API и укажите идентификатор модели и токен. Для своего провайдера нужен публичный HTTPS base URL до `/chat/completions`. Токен хранится в зашифрованном виде на сервере, а выбранный провайдер доступен на обоих устройствах.

Режим «Встроенный OpenRouter Free» использует `openrouter/free` и отдельный ключ `OPENROUTER_FREE_API_KEY` из Cloudflare Worker Secrets. Для собственных токенов Worker использует секрет шифрования `LLM_TOKEN_ENCRYPTION_KEY`. Если модель недоступна, таймер, журнал, статистика и экспорт продолжают работать.

Разбор отправляет выбранному провайдеру записи и заметки за период. Проверка модели отправляет короткий текстовый запрос без записей. Тарификация личного ключа зависит от провайдера и модели. Повторный запрос с тем же ID не запускает генерацию снова.

## Запуск

Нужны Node.js 24, npm и Python 3 для SQL-тестов.

```sh
npm ci
npm run migrate:local
npm test
npm run check
npm run dev
```

`npm run build` собирает PWA в `frontend/dist`. Команды `dev`, `test`, `check` и `deploy` выполняют сборку автоматически. Во время локальной разработки повторите сборку после правок интерфейса. Локальная D1 хранится в `.wrangler/`.

Локальный API требует подписанного JWT Cloudflare Access. Автоматические API-тесты используют тестовую подпись и SQLite. Проверку входа и синхронизации в браузере проводите на отдельном защищённом Worker с тестовой D1.

Для публикации используйте [инструкцию Cloudflare](docs/cloudflare-deployment.md). Рабочий `wrangler.production.jsonc` хранится локально. Приложение собирается и публикуется командой `npm run deploy -- --config wrangler.production.jsonc`.

## Код и данные

- `frontend/public` содержит интерфейс, manifest и service worker. Общий код календаря работает и в браузере, и в Worker.
- `backend` содержит API, доступ к D1 и вызовы провайдеров.
- `migrations` содержит добавочные миграции D1. При обновлении используйте прежнюю базу и сохраните её резервную копию.
- `tests` проверяет авторизацию, календарь, сохранение, отчёты, экспорт и кэш статической оболочки.

Сборка и автоматические проверки не заменяют приёмку реальных Cloudflare Access и D1, установки PWA на телефон и живых вызовов провайдеров.
